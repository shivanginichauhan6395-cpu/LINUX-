## Important safety notes
- Commands that use `sudo` require administrator privileges.
- These instructions target Ubuntu. Lab 8 uses `apt` and `dpkg`; it is not intended for RHEL-family systems.
- For Labs 9 and 10, use only the disposable disk-image/loop-device setup described in the lab. Never run `mkfs`, `fdisk`, or `parted` against your system disk or an unidentified device.
- Device names, PIDs, UUIDs, and command output vary between systems. Confirm the target device before running any storage command.
- Run each lab command only in a test environment and capture your own terminal output for practical records.
